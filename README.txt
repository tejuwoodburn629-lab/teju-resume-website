TEJU WOODBURN — RESUME WEBSITE

FILES
- index.html: page content and sections
- style.css: responsive design and print styling
- script.js: current year and Print / Save as PDF button

PREVIEW LOCALLY
1. Extract this ZIP file to a folder.
2. Open index.html in a browser.
3. Edit the text in index.html to update the page.
4. Keep all three files in the same folder.

PUBLISH
You can publish this static website with GitHub Pages (https://pages.github.com/) or Netlify (https://www.netlify.com/).

PRIVACY
The webpage displays the phone number, email address, and LinkedIn profile from the provided resume. If you do not want these publicly visible, remove or change them before publishing.
